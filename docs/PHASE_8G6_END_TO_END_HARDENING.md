# Phase 8G.6 — End-to-End Integration, Data Integrity & Operational Hardening

## Verified end-to-end flow

`python scripts/verify_phase_8g6_e2e.py` runs one synthetic orchestration replay against a temporary SQLite database, reads its records through FastAPI `TestClient`, recreates the app against the same database, and verifies that the session and report remain unchanged. It then gives Flutter's test HTTP client the exact JSON response bodies returned by FastAPI. The real Flutter API repository parses those bodies, and Live Mode renders the persisted session and its detail, the finding and its detail, the report and its detail, and storage availability. IDs, report/session linkage, finding references, fixture provenance, and the report manifest survive the path.

This is an end-to-end **workflow/API/Flutter integration test** using an in-process FastAPI test client and Flutter's injected response client. It does not launch Uvicorn or open a backend network socket. All state is temporary and removed after the script exits; no target or external service is contacted.

## Persistence and API integrity

- Schema version 1 initializes on an empty database. There is currently no migration from an older non-empty or future schema: unversioned non-empty and unsupported-version databases fail closed and are not rewritten.
- A report and its run sessions are committed atomically. Stable report/session identifiers deduplicate identical output. Concurrent duplicate writes and reads preserve report/session/finding counts.
- Multi-query session/report pages and dashboard aggregates now use a single read transaction, preventing totals from being sampled across different commits.
- Read-only SQLite URI construction now percent-encodes filesystem paths. A regression test covers spaces, `#`, and `%` in valid Windows paths.
- Missing and locked stores, malformed JSON, and semantically incomplete report payloads remain unavailable (HTTP 503); valid unknown record IDs return 404 and malformed IDs/queries return 422. Responses use generic errors without disclosing database paths or exception details.
- API contract tests cover actual harness values, provenance, report metrics and diagnostics, empty pages, pagination, read-only database bytes, linkage, and restart retrieval.

## Flutter Live Mode

Live Mode now opens a persisted session from the dashboard and loads its detail using the same session ID returned by the API. The detail view shows stored run, case, report, decision, fixture, result, and any actual diagnostic data. The repository validates key session/result identity and provenance fields. Existing finding and report detail paths are exercised with the same persisted IDs.

Loading and empty views remain distinct from HTTP/storage errors; settings explicitly shows unavailable storage, API errors do not reveal response bodies, and an explicit Retry reloads data without substituting demo fixtures. Repository tests cover timeout and malformed responses. The cross-stack widget test is opt-in when run as part of the ordinary `flutter test` suite; the integration script supplies its actual FastAPI response bundle and runs that widget test separately.

## Limitations and safety boundaries

- The store persists only completed synthetic offline harness output. Fixture rows remain `is_synthetic=true`, `is_empirical=false`, `execution_mode=offline_fixture`; no real-world vulnerability detection readiness is implied. `confidence_is_calibrated=false` remains in force.
- No schema migration beyond initial version 1 creation is implemented. Do not point this phase at an existing user database for migration or reset.
- The API has no authentication or authorization. Keep it isolated and loopback-only; do not expose it publicly.
- Live assessment submission, target scanning/exploitation, approved evidence ingestion, external model/provider calls, and model downloads remain unsupported or unauthorized. `docs/source-review-manifest.json` was not changed, no source was approved, and DEC-01 through DEC-08 remain pending. No empirical benchmark was run.
